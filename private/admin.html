Order editor — settings

Activity

What the portal has handled for you (resets if the app is redeployed on an ephemeral host).

What can customers do?

Fix shipping address
Let customers correct their delivery address (same country only).
Swap items / change variant
Switch size, grind, or another option of the same product.
Increase quantities
Buy more of an item — the difference is collected via an emailed pay link.
Reduce / remove items
Creates a refund you process in Shopify admin (flagged in the order's staff notes).
Cancel the whole order
Full self-service cancellation with refund to the original payment method. Run one live test before relying on it.
Add items / upsell
Offer the curated products below as post-purchase add-ons.

Rules

Allow swaps to pricier options
If off, customers can only switch to an equal or cheaper option. If on, the price difference is collected via an emailed pay link.
Email customer when an edit is made
Sends Shopify's order-updated email after address/swap changes.
Email a pay link for balances
When a swap or added item leaves a balance, email a secure Shopify payment link.
