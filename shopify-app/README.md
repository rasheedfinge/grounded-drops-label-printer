# Grounded Drops Gift Offers (BOGOS replacement)

A free replacement for the BOGOS Shopify app. Auto-adds free gifts, shows a
"pick your gift" slider, and supports BOGO — for **$0/month** instead of ~$70.

- **`extensions/gift-offers/`** — the theme app extension (the widget).
- **`SETUP.md`** — step-by-step install + how to configure offers.

Start with **[SETUP.md](./SETUP.md)**.
